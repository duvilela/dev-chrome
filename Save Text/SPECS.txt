SPECS extensão para SALVAR texto em TXT 
--------------------------------------------
Pergunta Minnha: É possível criar uma extensão no navegador que ao selecionar um texto , você clicar com o botão direito e ele já salva o texto selecionado em um document txt no seu computador ?


Resposta do GEMINI:

Sim, **é totalmente possível** criar uma extensão para o navegador que faça exatamente isso! No entanto, devido às regras de segurança dos navegadores modernos (como Chrome, Edge e Firefox), existe um pequeno detalhe sobre *como* esse arquivo é salvo.

Extensões não podem simplesmente "escrever" um arquivo direto em qualquer pasta do seu disco rígido sem que você saiba. Em vez disso, a extensão usa a API de downloads do navegador. Na prática, o fluxo fica assim: você seleciona o texto, clica com o botão direito, escolhe a opção da extensão, e o navegador **baixa automaticamente um arquivo `.txt` contendo aquele texto**.

Se você configurar o seu navegador para "Salvar arquivos automaticamente na pasta de Downloads" (sem perguntar onde salvar toda vez), o processo acontece com **um único clique**.

Aqui está como essa extensão é estruturada. Se você quiser testar no seu computador, basta criar uma pasta e colocar esses dois arquivos dentro dela:

---

### 1. O Manifesto (`manifest.json`)

Este arquivo é o "RG" da extensão. Ele diz ao navegador o que a extensão faz e quais permissões ela precisa (ler o menu de contexto e fazer downloads).

```json
{
  "manifest_version": 3,
  "name": "Salvar Texto Selecionado",
  "version": "1.0",
  "description": "Salva o texto selecionado em um arquivo .txt com o botão direito.",
  "permissions": [
    "contextMenus",
    "downloads"
  ],
  "background": {
    "service_worker": "background.js"
  }
}

```

### 2. O Script de Fundo (`background.js`)

Este é o código que realmente faz a mágica. Ele cria a opção no menu do botão direito e gera o arquivo `.txt` quando você clica nela.

```javascript
// Cria a opção no menu de contexto (botão direito) quando a extensão é instalada
chrome.runtime.onInstalled.addListener(() => {
  chrome.contextMenus.create({
    id: "salvarTextoTxt",
    title: "Salvar texto como .txt",
    contexts: ["selection"] // Só aparece quando algo estiver selecionado
  });
});

// Escuta o clique no menu
chrome.contextMenus.onClicked.addListener((info, tab) => {
  if (info.menuItemId === "salvarTextoTxt" && info.selectionText) {
    const texto = info.selectionText;
    
    // Transforma o texto em um formato que o navegador entende como arquivo (Data URL)
    const blobUrl = "data:text/plain;charset=utf-8," + encodeURIComponent(texto);
    
    // Sugere um nome de arquivo baseado na data/hora para não sobrescrever
    const dataAtual = new Date().toISOString().replace(/[:.]/g, "-");
    const nomeArquivo = `texto_selecionado_${dataAtual}.txt`;

    // Dispara o download automático
    chrome.downloads.download({
      url: blobUrl,
      filename: nomeArquivo,
      saveAs: false // Se for 'true', ele vai abrir a janela perguntando onde salvar
    });
  }
});

```

---

### Como testar isso agora mesmo no seu navegador (Chrome/Edge/Opera):

1. **Crie os arquivos:** 1 min.
Crie uma pasta vazia no seu computador (ex: `minha-extensao`). Dentro dela, crie dois arquivos de texto usando o Bloco de Notas: um chamado `manifest.json` e outro chamado `background.js`. Cole os códigos acima neles.


2. **Abra a página de extensões:** 30 segundos.
No Chrome, digite `chrome://extensions/` na barra de endereço (ou `edge://extensions/` no Edge) e aperte Enter.


3. **Ative o Modo do Desenvolvedor:** 10 segundos.
No canto superior direito da página, ative a chave chamada **"Modo do desenvolvedor"**.


4. **Carregue a extensão:** 30 segundos.
Clique no botão **"Carregar expandida"** (ou "Carregar desembalada") que apareceu no canto esquerdo e selecione a pasta que você criou.


Pronto! Agora vá em qualquer site, selecione uma frase, clique com o botão direito e teste.
